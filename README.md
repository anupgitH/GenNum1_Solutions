## Getting Started

### Prerequisites

- Java and Maven
- Node.js and npm
- PostgreSQL

### Frontend Setup

```bash
cd gennum1-frontend
npm install
npm run dev
```

### Backend Setup

From the project root:

```bash
./mvnw spring-boot:run
```

Configure the required database and API credentials through environment variables before running the backend.

## Environment Variables

Configure these variables in your local environment or deployment platform:

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`
- `GEMINI_API_KEY`
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

**Security:** Never commit real credentials, API keys, or passwords to GitHub.

## Deployment

- Frontend: Vercel or another static hosting provider
- Backend: A Java-compatible hosting provider
- Database: A hosted PostgreSQL provider

The frontend and backend must be configured to communicate using the deployed backend API URL.
